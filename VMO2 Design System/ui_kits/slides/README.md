# VMO2 Slide Kit

Recreates the 2024 PowerPoint toolkit's slide vocabulary in HTML. Each slide is a 1920×1080 frame; the deck uses `deck_stage.js` to scale to fit.

## Slide types
- **Title** — Big SHOUTY headline with corner swoosh + corporate lockup
- **Section divider** — Capsule + endcap label as a section opener on flat colour
- **Instant expert** — Direct port of the "Instant expert" layout from the toolkit: gradient header pill, body paragraph, four capsule-headed columns, "What's next?" sidebar
- **Two column** — Headline left, body right
- **Big stat** — Oversized numeral with caption
- **Quote** — Editorial pull quote with attribution
- **Closing** — Thank-you / contact

Open `index.html` to flip through the deck.
