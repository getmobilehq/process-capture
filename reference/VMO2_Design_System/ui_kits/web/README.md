# VMO2 Web UI Kit

A high-fidelity recreation of Virgin Media O2 Business' marketing-page vocabulary, built on the foundations in `/colors_and_type.css`.

> Note: no production codebase was provided. These are recreations from the 2024 PowerPoint toolkit + the public site's visual language. Flag with a designer for verification before shipping.

## Files
- `index.html` — assembled marketing landing page
- `Header.jsx` — sticky header with sub-brand switcher
- `Hero.jsx` — split hero with swoosh
- `CapsuleNav.jsx` — the signature pill + endcap tab strip
- `ProductGrid.jsx` — three-up product capsule cards
- `BigStat.jsx` — coverage / scale callout
- `Footer.jsx` — full footer

## Patterns demonstrated
- Capsule + endcap circle as section header AND tab nav
- Pill CTAs in O2 blue with bold sentence-case labels
- Soft drop shadows on otherwise flat cards
- Sub-brand sibling logos (VMB, O2B, giffgaff) in the footer cluster
